## Seção 1 — Fundamentos do Windows, área de trabalho, janelas e multitarefa

**Questão 01.** Um servidor público utiliza um computador com Windows 11 para executar simultaneamente um navegador, um editor de textos e uma planilha eletrônica. Durante a execução desses aplicativos, o sistema operacional gerencia recursos como memória, processador e dispositivos de entrada e saída.

Nesse contexto, a função primordial do Windows é

A) executar exclusivamente programas desenvolvidos pela Microsoft, impedindo a utilização de aplicativos de terceiros.

B) substituir fisicamente os dispositivos de hardware por componentes virtuais.

C) atuar como intermediário entre usuários, aplicativos e hardware, gerenciando recursos computacionais.

D) armazenar permanentemente todos os dados dos aplicativos na memória RAM.

E) executar apenas uma tarefa por vez, alternando automaticamente entre programas encerrados.

**Questão 02.** Durante a elaboração de um relatório, um usuário mantém diversas janelas abertas no Windows 10. Desejando visualizar rapidamente a área de trabalho, sem encerrar os aplicativos, ele utiliza uma combinação de teclas.

O atalho adequado para mostrar ou ocultar a área de trabalho é

A) Windows + E.

B) Windows + D.

C) Ctrl + D.

D) Alt + F4.

E) Windows + R.

**Questão 03.** Um usuário está trabalhando com três aplicativos abertos e deseja alternar rapidamente entre suas janelas, sem utilizar o mouse.

A) Ctrl + Esc.

B) Ctrl + Shift + N.

C) Windows + L.

D) Alt + Enter.

E) Alt + Tab.

B) todos os processos vinculados ao aplicativo são suspensos permanentemente.

D) a janela deixa de ocupar a área de trabalho, mas o aplicativo permanece aberto.

E) a minimização é equivalente ao encerramento da sessão do usuário.

**Questão 05.** Para organizar melhor seu trabalho, um servidor deseja visualizar as janelas abertas e administrar diferentes áreas de trabalho virtuais no Windows.

**Questão 07.** Um usuário fixa o ícone de determinado aplicativo na barra de tarefas do Windows 10.

A respeito dessa operação, assinale a afirmativa correta.

A) O aplicativo será executado automaticamente sempre que o computador iniciar.

## Seção 2 — Explorador de Arquivos: caminhos, tipos, cópia, movimentação e exclusão

**Questão 09.** Considere o seguinte endereço de arquivo, apresentado em um computador com Windows:

`C:\Projetos\2026\relatorio.pdf`

A interpretação correta desse caminho é:

A) Trata-se de um endereço relativo, que depende obrigatoriamente da pasta de trabalho atual.

B) Trata-se de um caminho absoluto na unidade C:, que identifica um arquivo denominado `relatorio.pdf` dentro de duas pastas.

C) O arquivo está localizado em uma pasta de rede, pois utiliza barras invertidas.

D) A extensão `.pdf` indica que o arquivo é executável.

E) O caminho identifica uma unidade de armazenamento removível, independentemente da configuração do computador.

**Questão 10.** Um usuário possui o arquivo `balanco.xlsx` e, pelo Explorador de Arquivos, altera seu nome para `balanco.pdf`, sem utilizar nenhum programa de conversão.

Nesse caso, é correto afirmar que

A) o Windows converte automaticamente a planilha em um documento PDF válido.

D) a renomeação não converte o formato interno do arquivo, podendo provocar dificuldades de abertura.

E) o Windows impede qualquer alteração de extensão em arquivos de planilha.

**Questão 11.** No Explorador de Arquivos do Windows 10, uma usuária seleciona um documento, pressiona Ctrl + C, navega para outra pasta e pressiona Ctrl + V.

B) a movimentação do documento para o destino, com exclusão do original.

C) a criação de um atalho para o documento, sem copiar seus dados.

D) a compactação automática do documento em formato ZIP.

E) a exclusão do documento original após sua transferência.

**Questão 12.** Um funcionário deseja transferir um arquivo da pasta `C:\Temporarios` para `C:\Documentos`, de modo que, concluída a operação, o arquivo não permaneça na pasta de origem.

Entre os procedimentos apresentados, o mais adequado é

**Questão 13.** Um usuário seleciona um arquivo armazenado em uma unidade local NTFS e pressiona Shift + Delete no Explorador de Arquivos.

Considerando o comportamento padrão do Windows, essa operação

A) renomeia o arquivo, removendo sua extensão.

## Seção 5 — Contas, permissões básicas, energia, recuperação e arquiteturas de 32 e 64 bits
